# 🛒 Fresh Card Store

**Fresh Card Store** is a modern e-commerce web application built with [Next.js 14](https://nextjs.org/).  
It provides a smooth shopping experience with a fast, responsive, and elegant design.

---

## 🚀 Features

- 🧩 **Modular Design** – Built with reusable components for scalability.  
- ⚡ **Next.js App Router** – Optimized routing and server-side rendering.  
- 💳 **Payment Integration** – Secure checkout with online payment options.  
- 🛍️ **Dynamic Product Pages** – Automatic rendering for each product.  
- 🧠 **Context API** – Manages global cart and user authentication states.  
- 🎨 **Tailwind CSS** – Clean and responsive UI design.  
- 🔒 **Authentication System** – Register, login, and protected routes.  

---

## 🧰 Tech Stack

- **Framework:** Next.js 14  
- **Language:** TypeScript  
- **Styling:** Tailwind CSS  
- **State Management:** React Context API  
- **Package Manager:** npm  
- **Authentication:** NextAuth.js  

---

## 🧑‍💻 Getting Started

Clone the repository:

```bash
git clone https://github.com/huthaifadl/fresh-card-store.git
cd fresh-card-store
```

Install dependencies:

```bash
npm install
```

Run the development server:
```bash
npm run dev
```

Then open your browser and go to 👉 http://localhost:3000

📂 Project Structure

```bash
src/
 ┣ app/
 ┃ ┣ (pages like home, login, register, cart, etc.)
 ┣ components/
 ┣ Context/
 ┣ PaymentActions/
 ┣ CartActions/
 ┣ apis/
 ┣ schema/
 ┗ utilities/
```
